## Curated overrides

```yaml
curated:
  justification: "Why this component matters for this stack (2-4 sentences)."
  requirements:
    - "Component-specific collection requirement."
  overrides:
    feeds:
      sysmon: {event_codes: [1]}                  # replaces defaults/derived for this feed
      corelight: {sourcetypes: [corelight_conn]}
    exclude_feeds: [netdev_syslog]                # drop a feed for this component
    cim: {datamodel: Endpoint, dataset: Processes, tags: [process, report], compliant_feeds: [sysmon]}
  notes: []
```

Precedence: `curated.overrides` > `config/dc_defaults.yml` > derived.
